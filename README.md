# Territorio NUMIC · Gran Matta Sur

Sitio web de divulgación socioespacial desarrollado en el marco de la colaboración entre el **Núcleo Milenio en Inseguridad y Cohesión Urbana (NUMIC, Proyecto ANID `NCS2025_047`)**, el **Centro de Investigación para el Desarrollo Local y Cultural (CEIDELC)** y la **Mesa Territorial Matta Sur (MTMS)**.

- **Portal web:** [https://territorio-numic.github.io/matta-sur](https://territorio-numic.github.io/matta-sur)

## Estructura del sitio

- `index.qmd`: Portada de presentación de la colaboración NUMIC – Gran Matta Sur.
- `02-numic-data-rda/2-processing/4-mattasur-analysis-report.qmd`: Diagnóstico territorial interactivo por manzana, barrio y Zonas MTMS (pestaña adicional en la web).
- `_quarto.yml`: Configuración del proyecto web Quarto compilado hacia `docs/` para despliegue en GitHub Pages.
